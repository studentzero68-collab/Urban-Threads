# Urban Threads

A streetwear e-commerce app built with HTML, CSS, and JavaScript, using Firebase for authentication and product data.

## Features

- Firebase Authentication (email/password sign up, login, logout)
- Product catalog fetched from Firestore, with category filtering (Hoodies, T-shirts, Sneakers, Accessories)
- Shopping cart with add/remove/quantity controls and a running total
- Cart access is restricted to logged-in users
- Responsive layout (CSS Grid/Flexbox)

## Tech Stack

- HTML, CSS, JavaScript
- Firebase Authentication
- Firebase Firestore

## Pages

- `index.html` — Landing page
- `shop.html` — Product listing with category filters
- `login.html` — Login / Signup
- `cart.html` — Cart and checkout summary

## Running Locally

Open `index.html` via a local server (e.g. VS Code's Live Server extension) — opening the file directly won't work since the app uses JavaScript modules.
